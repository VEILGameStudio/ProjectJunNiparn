# 03 — การแยกชั้นต้นไม้ (วิธีแก้ slime) + วิธีวาด

## 1. ชั้นของต้นไม้ในคลิป (ภาพ `img/w03-tree-layers.jpg`)

| ลำดับวาด (หลัง → หน้า) | ชั้น | ลม | ตัวละครดัน | หมายเหตุ |
|---|---|---|---|---|
| 1 | ลำต้น + กิ่ง | ไม่มี | ไม่มี | "we don't want it to sway" — มีเศษกิ่งลอย ๆ ที่โผล่ตามช่องใบด้วย |
| 2 | ใบหลัก (ทั้งพุ่ม) | เต็ม | **เต็ม** | ชั้นนี้คือที่แหวกออกตอนตัวละครทะลุ |
| 3 | ตัวละคร | – | – | อยู่ระหว่างชั้น 2 กับ 4 (จากภาพซูม 63–64 วิ) |
| 4 | ใบซ้ำเจาะรู (overlay) | **เท่ากับชั้น 2** | **น้อยมาก** ("dulled a lot") | ตอนนิ่งซ้อนพอดีกับชั้น 2 ทุกพิกเซล |

**หัวใจ:** ลมเท่ากัน ⇒ ตอนไม่มีใครแตะ ต้นไม้ดูเหมือนภาพเดียว (ไม่มีภาพซ้อน/เบลอ)
แรงดันไม่เท่ากัน ⇒ เฉพาะตอนถูกแตะ ชั้นล่างแหวกในขณะที่ชั้นบนนิ่ง → เห็นช่องลึกระหว่างชั้น = ความลึกที่ "เกิดขึ้นตอนโต้ตอบ"
นี่คือ "two interactions" ในคลิป

## 2. ชั้นใบเจาะรู — วัดจากคลิป

เทียบภาพชั้น 2 กับชั้น 4 ในพื้นที่เดียวกัน (sprite editor ซูมเท่ากัน):

| | ชั้นใบหลัก | ชั้นเจาะรู |
|---|---|---|
| พื้นที่ใบ | 100% | **~68%** (เหลือ 2/3) |
| ความสว่าง percentile 10 / 50 / 90 | 33 / 68 / 94 | 53 / 72 / 117 |
| พิกเซลที่ตรงกับชั้นหลัก | – | 90% (ที่เหลือคือขอบที่ต่างกันเล็กน้อย) |

⇒ รูถูกเจาะที่ **เฉดมืดที่สุด** (ร่องเงาระหว่างก้อนใบ) เป็นหลัก ชั้นบนจึงเป็น "ก้อนใบด้านที่โดนแสง" ลอยอยู่หน้า "มวลมืดด้านหลัง"
ซึ่งตรงกับตรรกะแสงจริง: ส่วนที่ยื่นออกมาหาเราโดนแสง ส่วนที่ลึกเข้าไปมืด

## 3. วิธีวาดชั้นเจาะรู (สำหรับ artist)

1. Duplicate layer ใบทั้งหมด
2. ลบ **เฉดมืดสุด 1 เฉด** ทิ้งทั้งหมด (ร่องเงา, ขอบล่างของแต่ละก้อน)
3. ลบเพิ่มเป็นจุด ๆ ขนาดประมาณ 2–5 px (pixel art) หรือ 1–3% ของความกว้างพุ่ม (งานวาดความละเอียดสูง) กระจายทั่ว ไม่ให้เป็นแผ่นทึบ
4. เป้าหมายพื้นที่ที่เหลือ **60–70%** — น้อยกว่า 50% ชั้นบนดูเป็นเศษ, มากกว่า 80% ชั้นล่างแทบไม่โผล่ตอนแหวก
5. **ห้ามขยับ/แก้รูปทรง** ของพิกเซลที่เหลือ — ต้องซ้อนพอดีกับชั้นล่างตอนนิ่ง
6. Export ขนาด canvas และ pivot เท่ากับชั้นล่างทุกประการ
7. ลำต้น: ใส่ปลายกิ่งเล็ก ๆ ที่ควรโผล่ตามช่องใบด้วย (ในคลิปมีเศษกิ่งลอยในชั้นลำต้น)

ตัวช่วย: `scripts/foliage_flow_sim.py` สร้างชั้นเจาะรูจากชั้นใบอัตโนมัติด้วยกฎข้อ 2–3 แล้วพิมพ์ % ที่เหลือ

## 4. ภาพจำลอง (Python ไม่ใช่ Unity)

`img/w06-sim-slime-vs-layered.png` — สองแถวบน: ชั้นเดียว (slime), สองแถวล่าง: แยกชั้นแบบคลิป (ตัวละครอยู่ในพุ่ม ถูกก้อนใบบังบางส่วน)
`img/w07-sim-layers.png` — ลำต้น / ใบ / ใบเจาะรู (61%) / รวม
`img/w08-sim.gif` — เคลื่อนไหวซ้าย = slime, ขวา = แยกชั้น

ปรับค่าได้: `python3 -I scripts/foliage_flow_sim.py <out> <overlay_scale=0.25> <wind_px=1.5> <disturb_px=6>`
ค่าเริ่มต้น overlay_scale = **0.25** (คลิปบอกแค่ "dulled a lot" ไม่ได้บอกตัวเลข) — แนวคิด: 0 = ชั้นบนนิ่งสนิทตอนโดนดัน (เสี่ยงดูแข็ง),
ยิ่งเข้าใกล้ 1 ยิ่งกลับไปเป็น slime ตัวเลขสุดท้ายต้องตัดสินจากภาพใน Unity

## 5. ใช้กับอะไรได้บ้าง

| พืช | แยกชั้นยังไง |
|---|---|
| ต้นไม้ใหญ่ที่ตัวละครทะลุผ่านได้ | ครบ 4 ชั้นตามตาราง §1 |
| ต้นไม้ใหญ่ที่อยู่ "หลัง" ทางเดิน (ทะลุไม่ได้) | ลำต้น + ใบ + overlay (ไม่ต้องอยู่หน้าตัวละคร) — ได้ความลึกจากลมอย่างเดียว ไม่ต้องใช้ disturbance |
| พุ่มเตี้ย/mini tree ที่เดินชน | 2 ชั้นพอ (ใบ + overlay), หรือทั้งก้อนสั่นด้วย vertex แบบ impulse |
| หญ้าเป็นแถบ | ไม่ต้อง overlay — ใช้ height mask แทน (ดู `04-unity-urp.md` §5) |
