# 03 — กับดักความชัดเฉพาะกล้อง HD-2D ของเกมนี้

ค่ากล้องล็อกใน CLAUDE.md §7 (ห้ามแก้) ปัญหาความชัดแก้ด้วย **การวางของและอาร์ต**

## ThreeQuarter (ortho size 5, pitch 30°, yaw 45°)

| กับดัก | อาการ | แก้ |
|---|---|---|
| **sprite สูงขอบล่างจอ** | ต้นไม้/เสา/ตู้ที่อยู่ใกล้กล้อง (ด้านล่างจอ) บังพื้นและของด้านหลัง | ของสูงวางชิดผนังด้านบนจอ (ไกลกล้อง); ด้านล่างจอใช้ของเตี้ย |
| **ผนังด้านหน้า** | ผนังฝั่งกล้องบังห้อง | ห้อง diorama ตัดผนัง/หลังคาฝั่งกล้อง (GDD: บ้าน diorama ตัดหลังคา) |
| **yaw 45°** | ห้องสี่เหลี่ยมกลายเป็นเพชรบนจอ มุมซ้าย/ขวาไกลสุดอยู่ติดขอบจอ | ของสำคัญอยู่แถวกลาง ไม่อยู่ที่มุมซ้าย/ขวาของเพชร |
| **orthographic ไม่มีขนาดตามระยะ** | ของไกลกับของใกล้ขนาดเท่ากัน บอกความลึกยาก | ใช้เงา blob ใต้ของ (CLAUDE.md: sprite ไม่สร้างเงา ใช้ blob shadow), value ไกลจางลงเล็กน้อย |
| **พื้นลายเยอะ** | ของคลิกได้จมในลายพื้น | พื้นลายนุ่ม contrast ต่ำ; รอบของสำคัญให้พื้นเรียบ |
| **ห้องใหญ่กว่าจอ** | ผู้เล่นไม่รู้ว่ามีอะไรนอกจอ | ห้อง ≤ ~11×11 หน่วย หรือให้ของที่ล้นขอบจอ "โผล่" มาบางส่วนเพื่อบอกว่ามีต่อ |

## SideView (FOV 19, ระยะ 20, ลึกเดินได้ ~3 หน่วย)

| กับดัก | อาการ | แก้ |
|---|---|---|
| **foreground lip / ชั้นหน้ากล้อง** | บังของบนระนาบเดิน | ห้ามวางของคลิกได้หลัง foreground; foreground มืด contrast ต่ำ (ย้อนแสง) ให้ตาข้ามไป |
| **ลึก 3 หน่วย** | ผู้เล่นไม่รู้ว่าเดินเข้าลึกได้ | ของที่ต้องเข้าไปหาวางบนระนาบเดินหลัก ไม่ซ่อนลึกสุด |
| **ชั้นไกลหลายชั้นสว่าง** | ตาไปที่ฉากหลังแทนทางเดิน | ฉากหลังจาง (`sideview-forest-background` ชั้น haze) ระนาบเดิน contrast สูงสุด |
| **ตัวละคร 23% ของจอ** | ของเล็กบนพื้นหายง่าย | ของคลิกได้อย่างน้อย ~ครึ่งหนึ่งของความสูงภวิน หรือมีประกาย |
| **ทางยาวว่าง** | ไม่รู้ว่ามาถูกทางไหม | มีเหตุการณ์/landmark ทุก 1–2 จอ (~12–24 หน่วย) |

## ทั้งสองกล้อง

- **เปลี่ยนโซน = ตัดภาพหลัง fade** (CLAUDE.md §7) — หลังตัดภาพ ผู้เล่นต้องรู้ทันทีว่าอยู่ตรงไหน: เกิดหันหน้าเข้าห้อง, landmark อยู่ในจอ
- **จุดเกิดหลังเข้าประตู** ห่างจากประตูพอที่จะไม่เดินย้อนออกโดยบังเอิญ และหันไปทางที่ควรไป
- **จอกว้าง 21:9** เห็นข้างมากขึ้น อย่าซ่อนของไว้นอกขอบ 16:9 โดยคิดว่าไม่มีใครเห็น
- **UI** ห้ามทับระนาบเดิน/ของสำคัญ (ดู `sideview-forest-background`: ออกแบบฉากรอบ UI ตั้งแต่ rough); UI scale ตาม CLAUDE.md §7
