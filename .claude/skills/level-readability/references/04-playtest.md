# 04 — เทสต์กับคนเล่นครั้งแรก

คนทำด่านรู้คำตอบแล้ว จึง "มองไม่เห็น" ปัญหาความชัด ต้องดูคนที่ไม่เคยเห็นด่าน

## วิธี (15–30 นาที ต่อคน)

1. **คนเล่น**: ไม่เคยเห็นด่านนี้ ไม่ใช่คนในทีมที่ทำห้องนี้ (เพื่อนต่างแผนก, คนในครอบครัวอายุ 13+)
2. **พูดก่อนเริ่มแค่**: "ลองเล่นตามสบาย คิดอะไรพูดออกมาเลย เราจะไม่ช่วยนะ" — ห้ามอธิบายด่าน
3. **คนดูเงียบ** จดอย่างเดียว ห้ามชี้ ห้ามบอกใบ้ ห้ามแก้ตัวแทนเกม
4. ถ้าติดเกิน 5 นาทีโดยไม่มีความคืบหน้า → จดว่า "ติด" แล้วค่อยใบ้ (นับเป็นจุดที่ต้องแก้)
5. จบแล้วถาม 3 ข้อ: "ตอนเข้ามาคิดว่าต้องทำอะไร", "ตรงไหนงงที่สุด", "ของไหนคิดว่าคลิกได้แต่คลิกไม่ได้"

## สิ่งที่จด (ตาราง)

| เวลา | เหตุการณ์ | ความหมาย |
|---|---|---|
| คลิกครั้งแรก (วินาที) | ช้า > 20 วิ | ไม่รู้ว่าอะไรคลิกได้ |
| คลิกของประดับ | นับครั้ง + ของอะไร | ของประดับหน้าตาเหมือนของคลิกได้ |
| เดินไปทางตัน | ที่ไหน | ทางตันดูเป็นทาง |
| มองข้าม clue/ของ | อะไร เดินผ่านกี่ครั้ง | contrast ต่ำ / ถูกบัง / นอกทาง |
| พูดว่า "อ๋อ" | puzzle ไหน | puzzle ทำงาน ✓ |
| พูดว่า "ห๊ะ / อะไรวะ" | ตรงไหน | จุดที่ต้องแก้ |
| highlight idle ขึ้น | กี่ครั้ง ที่ไหน | ผู้เล่นค้าง |
| เวลาต่อ puzzle | นาที | เทียบเป้า (puzzle-design 03 §4) |

## สรุปหลังเทสต์

- ปัญหาที่เจอ **2 คนขึ้นไป** = แก้แน่นอน, 1 คน = จดไว้ดู
- แก้ตามลำดับ: ค้างถาวร > หลงทาง > มองไม่เห็นของ > คลิกมั่ว > สวยน้อย
- แก้ที่ฉากก่อน (ย้ายของ, value, แสง) แล้วค่อยเพิ่มคำใบ้/บทพูด
- เทสต์ซ้ำกับ **คนใหม่** (คนเดิมรู้คำตอบแล้ว)
