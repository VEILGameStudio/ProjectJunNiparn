# 01 — ลำดับชั้นการมอง

## 1. ตัวแปรที่ทำให้ "เด่น" (เรียงจากแรงสุด)

| ตัวแปร | เด่นเมื่อ | หมายเหตุ |
|---|---|---|
| **Value (ความสว่าง)** | ต่างจากรอบข้างมาก | ตัวที่สำคัญสุด — ตาเห็น value ก่อนสี อ่านออกแม้คนตาบอดสี |
| **ขอบ (edge)** | ขอบคม/เส้นหนา บนพื้นหลังที่นุ่ม | ฉากในเกมนี้มีหมอก/ชั้นไกลนุ่ม → ของใกล้คม = เด่นเอง |
| **Saturation** | อิ่มกว่ารอบข้าง | ฉาก ANODARD ฐานเย็นหม่น → accent สดหนึ่งสีพอ (`sideview-forest-background` ข้อ 5) |
| **Hue** | ร้อนบนเย็น / คู่ตรงข้าม | ใช้หลัง value; อย่าพึ่งแดง–เขียวอย่างเดียว |
| **การเคลื่อนไหว** | ขยับในฉากนิ่ง | ประกาย/ลอยเบาๆ บนของสำคัญ (DOTween) — ระวังลมใบไม้ (`sprite-wind-foliage`) แย่งตา |
| **ขนาด / แยกตัว** | ใหญ่กว่า หรือมีที่ว่างรอบตัว | ของคลิกได้ที่อยู่กลางกองของประดับ = หาย |
| **detail** | รายละเอียดเยอะกว่ารอบข้าง | ให้ detail สูงสุดที่ของสำคัญ ไม่ใช่ที่ฉากหลัง |

## 2. ชั้นของฉากเกมนี้ (สูงสุด → ต่ำสุด)

| ชั้น | ควรเป็น |
|---|---|
| 1 ภวิน / NPC ที่คุยได้ | value ต่างจากพื้นมากสุด, เส้นหนาสุด, อิ่มสุด |
| 2 lock / ของ puzzle / ประตูที่ต้องไป | ต่างชัด + highlight (มีแล้ว) + อาจมีประกาย |
| 3 ทางเดิน / ช่องเปิด | สว่างกว่าทางตัน, พื้นต่อเนื่อง |
| 4 ของประดับ (หญ้า ดอก หิน) | contrast ต่ำ ขอบนุ่ม ไม่ตัดกับชั้น 1–2 |
| 5 ฉากหลัง | จาง หม่น ไม่มี detail แย่ง |

กฎข้อเดียวที่จำ: **ชั้นล่างห้ามมี contrast สูงกว่าชั้นบนที่อยู่ใกล้กัน**

## 3. ภาษาของของคลิกได้

ทีมตกลงกันครั้งเดียว ใช้ทั้งเกม (ข้อเสนอ — ยืนยันกับ Oak/อาร์ตไดเรกเตอร์ก่อนบังคับใช้):
- **ขอบ**: ของคลิกได้มีเส้นรอบนอกเข้มกว่าของประดับ (ศิลปินวาด ไม่ใช่ shader ใหม่)
- **ตำแหน่ง**: วางบนพื้นที่ว่าง มีระยะหายใจรอบตัว ไม่อยู่ในกองของประดับ
- **highlight**: outline ขาวนุ่ม (CLAUDE.md §7) ขึ้นเมื่อเข้าใกล้และเมื่อ idle — ห้ามมีระบบ highlight ที่สอง
- **clue**: สัญลักษณ์ชุดเดียวกับ lock (รูปทรงเหมือนกัน แม้สีต่าง)
- **ของประดับที่หน้าตาคล้ายของคลิกได้** (กล่อง/ลิ้นชัก/ประตูประดับ): ทำให้ดูเปิดไม่ได้ชัดๆ (ไม่มีหูจับ, จมในผนัง, contrast ต่ำ) หรือให้คลิกได้แล้วตอบด้วย Mini dialogue สั้นๆ (`ContainerInteractable` แบบว่าง)

## 4. ตัวเลขช่วยตัดสิน (สคริปต์รายงาน)

- **Contrast ของกล่องกับวงรอบ** (luminance ratio แบบ WCAG ระหว่างค่ากลางในกล่องกับวงรอบนอก):
  ≥ 2.0 ดี · 1.5–2.0 พอ · < 1.5 **LOW** (หรี่ตาแล้วหาย)
- **ภวินควรมี contrast สูงสุด** หรือใกล้สูงสุดในภาพ
- ตัวเลขเป็นแนวทางเริ่มต้นของทีม ไม่ใช่กฎใน CLAUDE.md — สิ่งที่ตัดสินจริงคือคนเล่น (`04-playtest.md`)
