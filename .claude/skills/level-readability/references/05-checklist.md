# 05 — Checklist ก่อนส่งฉาก

## 3 วินาทีแรก
- [ ] บอกได้ว่าอยู่ไหน (landmark อยู่ในจอ)
- [ ] เห็น lock / เป้าหมาย
- [ ] เห็นทางไปต่ออย่างน้อยหนึ่งทาง
- [ ] ภวินเด่นที่สุดในภาพ (สคริปต์: `player` contrast สูงสุดหรือใกล้)

## ของคลิกได้
- [ ] ทุกชิ้น contrast ≥ ~1.5 กับรอบข้าง (สคริปต์ไม่ขึ้น `LOW`)
- [ ] ไม่จมในกองของประดับ มีที่ว่างรอบตัว
- [ ] ของประดับไม่มีหน้าตาเหมือนของคลิกได้
- [ ] collider คลิก (กล่องใหญ่) ครอบทั้งภาพของชิ้นนั้น — คลิกตรงไหนของภาพก็ติด (CLAUDE.md §6)
- [ ] clue ใช้สัญลักษณ์/รูปทรงเดียวกับ lock ที่มันใช้
- [ ] ~3–8 จุดต่อห้อง

## ทาง
- [ ] ทางไปสว่าง/เปิดกว่าทางตัน
- [ ] ทางตันจบด้วยสิ่งที่เห็นว่ากั้น (ไม่ใช่ collider ล่องหนกลางพื้นโล่ง)
- [ ] SideView: ทางหลักไปขวา, มีเหตุการณ์ทุก 1–2 จอ
- [ ] จุดเกิดหลังเข้าประตูหันเข้าห้อง เห็น landmark

## การบัง
- [ ] ThreeQuarter: ไม่มีของสูงที่ขอบล่างจอบังของสำคัญ
- [ ] SideView: ไม่มีของคลิกได้หลัง foreground
- [ ] UI ไม่ทับของสำคัญ ทั้ง 16:9 และ 21:9

## ภาษาภาพ
- [ ] สัญลักษณ์ผู้พิทักษ์ (ดอกไม้/สายน้ำ/ดวงอาทิตย์/ภูเขา) ใช้ความหมายเดิม
- [ ] ประตูที่ล็อกหน้าตาแบบเดียวกับที่อื่นในเกม
- [ ] สีไม่ใช่สิ่งเดียวที่แยกของ (มี value/รูปทรงช่วย)

## ไม่ชนกฎ
- [ ] ไม่ได้แก้ค่ากล้อง ไม่ได้เขียนโค้ด sort sprite ไม่ได้ใช้ alpha blending ไม่ได้ปรับ brightness จากฉาก

## คนเล่นจริง
- [ ] เทสต์กับคนไม่เคยเห็นอย่างน้อย 1–2 คน (`04-playtest.md`)
