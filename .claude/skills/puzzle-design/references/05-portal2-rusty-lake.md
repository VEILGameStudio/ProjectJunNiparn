# 05 — บทเรียน puzzle จาก Portal 2 และเกมตระกูล Rusty Lake

Oak สั่งให้ใช้เกมสองค่ายนี้เป็นกรอบความคิดหลักในการออกแบบ puzzle (2026-11-06)
ไฟล์นี้เก็บแค่ **วิธีคิด** ห้ามลอกเนื้อหาของเกมเหล่านั้น (ตัวละคร ภาพ ฉาก puzzle ชื่อเฉพาะ)
puzzle ของเราต้องมาจากหิมพานต์ × Solarpunk และเรื่องของภวินเท่านั้น

| | Portal 2 (Valve, 2011) | Rusty Lake (Cube Escape, Rusty Lake Hotel / Roots / Paradise …) |
|---|---|---|
| เป็นเกมแบบ | puzzle ฟิสิกส์ใน "ห้องทดสอบ" ทีละห้อง | point & click หนีออกจากห้อง เรื่องแปลกเหนือจริง |
| เก่งเรื่อง | **สอนกลไกโดยไม่ใช้ข้อความ**, ห้องที่อ่านออกทันที, เทสต์กับคนจริงหนัก | **puzzle ที่เล่าเรื่อง**, ห้องเล็กที่ทุกอย่างมีความหมาย, ความลึกลับที่เชื่อมกันข้ามเกม |
| ใกล้ ANODARD ตรงไหน | โครงสร้างการสอนและความชัดของห้อง | แนวเกม (GDD อ้าง Rusty Lake Paradise ตรงๆ) วิธีเล่าเรื่องและชนิด puzzle |

## A. จาก Portal 2 — "ทำให้ผู้เล่นรู้สึกฉลาด"

### A1. หนึ่งห้อง หนึ่งความคิดใหม่
แต่ละห้องทดสอบของ Portal 2 แนะนำกลไกใหม่ **อย่างเดียว** หรือผสมของเก่าที่รู้แล้ว **อย่างเดียว** ไม่เคยสองอย่างพร้อมกัน
→ ของเรา: puzzle เล็กแต่ละอันมี "อ๋อ" เดียว (หัวใจข้อ 1) และด่านหนึ่ง **สอนเรื่องใหม่เรื่องเดียว** (level-design-qa คำถามที่ 4)

### A2. สอน → ทดสอบ → บิด → ผสม
ห้องแรกของกลไกเกือบแก้ตัวเอง (ทำผิดไม่ได้) ห้องต่อมาให้ใช้เอง ต่อมาบิด สุดท้ายผสมกับกลไกเก่า
→ ของเรา: ด่านแรกของดินแดนใหม่สอนกลไกของดินแดนนั้นด้วย puzzle เล็กที่ผิดไม่ได้ และเขาเมรุคือ "ห้องผสม" ของทั้งเกม
(`01-puzzle-types.md` §3–4)

### A3. สอนด้วยฉาก ไม่ใช่ด้วยข้อความ
Portal 2 แทบไม่อธิบายอะไรเป็นตัวหนังสือ ผู้เล่นเห็นสิ่งของทำงานก่อน (เช่นเห็นของไหลผ่านระบบหนึ่งรอบ) แล้วค่อยได้ลงมือเอง
→ ของเรา: ก่อนให้ผู้เล่นใช้กลไก ให้ **เห็นมันทำงานหนึ่งครั้ง** ในที่ปลอดภัย เช่นเห็นสัตว์ตัวเล็กติดกับดักแบบเดียวกันก่อนจะเจอมอนตัวใหญ่
(`04-monsters-and-traps.md` §1 ขั้น "สอนนิสัย")

### A4. ภาษาภาพที่ไม่โกหก
พื้นผิวที่ยิงพอร์ทัลได้หน้าตาต่างจากพื้นผิวที่ยิงไม่ได้ **ตลอดทั้งเกม** และของที่เล่นได้มีสี/รูปทรงสม่ำเสมอ ผู้เล่นจึงไม่ต้องลองมั่ว
→ ของเรา: ตกลง "ภาษา" ครั้งเดียวแล้วห้ามแหกกฎ: ของคลิกได้, clue, lock, สัญลักษณ์ผู้พิทักษ์ 4 ตัวจาก P7 (`level-readability` หัวใจข้อ 2, 7)
ถ้าครั้งหนึ่งของที่หน้าตาเหมือนของคลิกได้กลับคลิกไม่ได้ ผู้เล่นจะเลิกเชื่อฉากทั้งเกม

### A5. เห็นทางออกก่อน
ห้องส่วนใหญ่ให้เห็นประตูทางออกตั้งแต่เข้า ผู้เล่นรู้เป้าหมาย คำถามเหลือแค่ "ไปยังไง"
→ ของเรา: เห็น lock ก่อน key (หัวใจข้อ 2) และ lock ของ puzzle ใหญ่อยู่ตรงข้ามทางเข้า (`level-design-qa` 02 §2)

### A6. ตัดสิ่งที่ทำให้ติดเพราะ "มองไม่เห็น" ไม่ใช่เพราะ "คิดไม่ออก"
ทีม Valve เทสต์กับคนเล่นจริงซ้ำๆ จุดไหนผู้เล่นติดเพราะไม่เห็นของ ไม่ได้มองขึ้น หรือไม่รู้ว่ามีตัวเลือก จะถูกแก้ด้วยแสง การวางของ หรือย้ายของมาอยู่ระดับสายตา
ส่วนจุดที่ติดเพราะ "ยังคิดไม่ออก" เก็บไว้ เพราะนั่นคือตัว puzzle
→ ของเรา: ตอนเทสต์ แยกให้ออกว่าติดแบบไหน (`level-readability` 04-playtest) ติดเพราะมองไม่เห็น = แก้ฉาก, ติดเพราะคิด = ปรับคำใบ้

### A7. ตัดตัวหลอกและทางที่เกือบถูก
ห้องทดสอบแทบไม่มีของที่ไม่ได้ใช้ ของทุกชิ้นในห้องคือส่วนหนึ่งของคำตอบ ผู้เล่นจึงใช้ "ของที่เหลือ" เป็นคำใบ้ได้
→ ของเรา: ในพื้นที่ puzzle ของที่คลิกได้ควรเกี่ยวกับ puzzle เกือบทั้งหมด สคริปต์เตือนไอเทม/clue ที่ไม่มีใครใช้ไว้แล้ว (`02-dependency-chart.md`)

### A8. อารมณ์ขันและบุคลิกเป็นรางวัล
บทพูดของตัวละครหลังแก้เสร็จคือรางวัลที่ทำให้อยากไปต่อ
→ ของเรา: หลัง puzzle ใหญ่ให้ภวิน ยาย หรือพ่อหมอครามพูดบางอย่างที่มีบุคลิก (ภวินปากแข็ง, ยายมีอารมณ์ขัน) ไม่ใช่แค่ "ประตูเปิดแล้ว"

## B. จาก Rusty Lake — "puzzle คือเรื่อง"

### B1. ห้องเล็ก แน่น ทุกอย่างมีความหมาย
เกม Cube Escape แต่ละภาคอยู่ในห้องเดียวหรือไม่กี่ห้อง แต่ทุกลิ้นชัก ทุกภาพบนผนัง มีบทบาท ผู้เล่นสำรวจลึก ไม่ใช่สำรวจกว้าง
→ ของเรา: ห้อง ThreeQuarter ≤ ~11×11 หน่วย มีจุดคลิก 3–8 จุดที่ **ทุกจุดให้อะไรบางอย่าง** (clue, ไอเทม, บทพูดที่เล่าเรื่อง) — P1 ห้องพระคือตัวอย่างที่ดี

### B2. puzzle ต้องบอกอะไรเกี่ยวกับโลก
คำตอบของ puzzle ใน Rusty Lake มักเป็นความลับของครอบครัวหรือพิธีกรรม แก้เสร็จแล้วผู้เล่นรู้เรื่องมากขึ้น
→ ของเรา: ทุกการ์ดต้องตอบช่อง "ผ่านแล้วได้รู้อะไรเกี่ยวกับโลก" (template §1) เช่น P7 เผยว่าผู้พิทักษ์ 4 คือใคร P3 เผยว่ากินรีปลุกป่าด้วยเพลง

### B3. โครงสร้างตามธีมที่ซ้ำเป็นบท
Rusty Lake Paradise แบ่งเป็นบท แต่ละบทมีธีมเดียว (ภัยพิบัติหนึ่งอย่าง) ที่ทุก puzzle ในบทเกี่ยวข้อง และแต่ละบทจบด้วยพิธีกรรม/เหตุการณ์ใหญ่
→ ของเรา: แต่ละดินแดน = หนึ่งบท ธีมคืออาการตอนมณีแตก (ภาพลวงตา / น้ำแห้ง / หมอก / แผ่นดินร้าว) ทุก puzzle ในดินแดนแก้อาการนั้นทีละส่วน และจบด้วยการได้มณี + cutscene (CLAUDE.md §7: cutscene ก่อนเก็บมณี)

### B4. ซูมเข้าไปดู
ของสำคัญถูกดูใกล้ในหน้าจอซูม (กล่อง, กลไก, หน้ากระดาษ) ที่ puzzle เกิดขึ้นจริง ฉากห้องเป็นแค่แผนที่ว่าอะไรอยู่ไหน
→ ของเรา: ตรงกับ `MiniGameBase` (เปิด UI ของตัวเอง ล็อก input ปิดตัวเอง) puzzle B, D, E, F ใช้หน้าจอซูม ส่วนห้องใช้หาและพาไป

### B5. วงจร "หาของ → ใช้ของ → ได้ของ" ที่ต่อกันเป็นโซ่สั้นๆ หลายเส้น
แต่ละห้องมีโซ่หลายเส้นพร้อมกัน เส้นละ 2–4 ขั้น ผู้เล่นติดเส้นหนึ่งก็ไปทำอีกเส้น
→ ของเรา: รูปเพชรในผังพึ่งพา (`02-dependency-chart.md` §4) และสคริปต์เตือนเมื่อมีงานให้ทำได้แค่อย่างเดียวติดกัน
**ระวัง:** Rusty Lake ใช้ combine ไอเทมเยอะ แต่ของเรา **ยังไม่มี combine** (Oak ตัดสิน) แทนด้วยการใช้ไอเทมกับของในฉากทีละขั้น

### B6. สัญลักษณ์และสิ่งที่วนกลับมา
มีสัญลักษณ์ สิ่งของ และสัตว์ที่โผล่ซ้ำข้ามห้องและข้ามภาค ผู้เล่นที่สังเกตได้รู้สึกได้รางวัล
→ ของเรา: สัญลักษณ์ผู้พิทักษ์ 4 ตัว, สร้อยของภวิน (มณีทวิภพ), เส้นสีเขียวในบ้านยาย, ภาพวาดหิมพานต์ ควรโผล่ซ้ำในทุกดินแดนเป็น clue หรือ payoff
สมุดของยายเป็นที่เก็บความหมายเหล่านี้ (Journal ยังไม่มีระบบ ใช้บทพูด/ไอเทมแทนไปก่อน)

### B7. แปลกได้ แต่ต้องมีตรรกะภายใน
Rusty Lake แปลกและน่าขนลุก แต่ puzzle ที่ดีที่สุดของมันมีเหตุผลในโลกของมันเอง ส่วนที่ผู้เล่นบ่นคือ puzzle ที่ต้องเดา ("moon logic")
→ ของเรา: หิมพานต์แฟนตาซีได้เต็มที่ แต่ทุกคำตอบต้องอธิบายได้จากกฎที่เกมเคยแสดงแล้ว (checklist ยุติธรรม `03-fairness-and-hints.md` §1)
และโทนของเราคือ **cozy 13+** เอาความลึกลับมา ไม่เอาความสยอง

### B8. ความลับที่ไม่บังคับ
มีความลับ/ฉากจบพิเศษสำหรับคนที่สำรวจลึก ทางหลักจบได้โดยไม่ต้องเจอ
→ ของเรา: ไอเทมลับ (Secret) เป็น gallery entry ใน CLAUDE.md §7 อยู่แล้ว ใช้เป็นรางวัลการสำรวจ ห้ามให้ทางหลักต้องใช้มัน

## D. คำถามเร็วก่อนส่งการ์ด

1. (Portal) puzzle นี้แนะนำความคิดใหม่กี่อย่าง → ต้องเป็น 1
2. (Portal) ผู้เล่นเห็นกลไกนี้ทำงานก่อนลงมือเองไหม
3. (Portal) ของทุกชิ้นในพื้นที่นี้มีบทบาทไหม และภาษาภาพไม่โกหกไหม
4. (Rusty Lake) แก้แล้วผู้เล่นรู้อะไรใหม่เกี่ยวกับโลก/ตัวละคร
5. (Rusty Lake) มันเข้าธีมของดินแดน (บท) นี้ไหม
6. (Rusty Lake) มีสัญลักษณ์ที่วนกลับมาจากที่อื่นในเกมไหม
7. (ทั้งสอง) คนที่ไม่รู้คำตอบอธิบายเหตุผลของคำตอบได้หลังแก้เสร็จไหม (ถ้าไม่ได้ = moon logic)
