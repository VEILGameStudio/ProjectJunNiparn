# 03 — ความยุติธรรม, คำใบ้, ความยาก

## 1. Checklist ความยุติธรรม (ต้องผ่านทุกข้อ)

- [ ] เขียน "อ๋อ" ได้ในประโยคเดียว
- [ ] ผู้เล่น **เห็น lock ก่อน** ได้ key (หรืออย่างน้อยได้ key แล้วรู้ทันทีว่าใช้กับอะไร)
- [ ] ทุกข้อมูลที่ต้องใช้อยู่ในเกม — ไม่ต้องรู้นอกเกม (ยกเว้นที่ GDD ตั้งใจ)
- [ ] clue หน้าตา "เชื่อมกับ" lock: สัญลักษณ์/สี/รูปทรง/ชื่อเดียวกัน
- [ ] clue สำคัญหาเจอได้อย่างน้อย 2 ทาง (ภาพ + บทพูด, หรือสองที่)
- [ ] ไม่มีคำตอบที่ "ถูกแต่เกมไม่รับ" — ถ้าคำตอบอื่นที่สมเหตุสมผลมีอยู่ ให้เกมรับ หรือให้ภวินพูดว่าทำไมไม่ใช่
- [ ] ลองมั่วแล้วผ่านไม่ได้ง่ายกว่าคิด (ตัวเลือก ≥ ~20 แบบ หรือผิดแล้ว reset)
- [ ] ผิดแล้วไม่ลงโทษหนัก (เกม cozy): reset puzzle ได้ ไม่เสียไอเทม ไม่ game over ยกเว้น Oak สั่ง
- [ ] **ไม่มีทางค้างถาวร**: ไอเทมใช้หมดเฉพาะขั้นสุดท้าย (CLAUDE.md §8), clue ไม่อยู่หลัง lock ตัวเอง, puzzle ที่แก้แล้ว restore ถูก (silent restore)
- [ ] เล่นได้โดยปิดเสียง (มีภาพแทนเสียง) และไม่ต้องแยกสีแดง-เขียวอย่างเดียว (ใช้รูปทรงด้วย)
- [ ] ข้อความ "ต้องมีของ" กับ "ต้องถือของ" เป็นสองประโยค (CLAUDE.md §8)
- [ ] ภาษา: ถ้าคำตอบเป็นคำ/ตัวอักษร คิดแล้วว่าเล่นภาษาไทย/อังกฤษเป็นยังไง

## 2. บันไดคำใบ้ 3 ขั้น

GDD: NPC ให้คำใบ้ตอนผู้เล่นติด **แต่ไม่เฉลยตรงๆ** — ระบบที่มี: `HintManager` + highlight เมื่อ idle (CLAUDE.md §7),
Mini/Full dialogue ของ NPC (พ่อหมอคราม, ยาย, ผู้พิทักษ์)

| ขั้น | ชื่อ | ทำอะไร | ตัวอย่าง (P1) |
|---|---|---|---|
| 0 | ฟรี | highlight ของที่คลิกได้เมื่อเข้าใกล้ / idle | กรอบรูป ปฏิทิน ลิ้นชัก นาฬิกา เรืองขาว |
| 1 | กระซิบ | ย้ำ **เป้าหมาย** | ยาย: "กุญแจน่าจะอยู่ในห้องพระนะลูก" |
| 2 | ชี้ | ชี้ **ที่** ที่ต้องดู | ภวิน: "ของในห้องนี้มีรูปแปลกๆ ติดอยู่ทุกชิ้นเลย" |
| 3 | เกือบบอก | ชี้ **ความสัมพันธ์** (ยังไม่บอกคำตอบ) | ภวิน: "รูปบนแม่กุญแจ…เหมือนรูปบนของพวกนั้นเลย ตัวเลขข้างๆ คือลำดับรึเปล่า" |

กฎ:
- คำใบ้ทุกขั้นเป็น dialogue asset (team-requests §2.11) ไม่ใช่ข้อความพิมพ์ใส่ช่อง
- เวลาที่จะเลื่อนขั้นคำใบ้ = ตั้งใน Inspector (idle time) ไม่ hardcode
- ห้ามคำใบ้ที่เป็นคำตอบตรงๆ ถ้าอยากมี "เฉลย" ต้องเป็นทางเลือกที่ผู้เล่นขอเอง และต้องถาม Oak

## 3. ความยาก

ความยากมาจาก 4 ปุ่ม ปรับทีละปุ่ม:

| ปุ่ม | ง่าย | ยาก |
|---|---|---|
| ระยะ clue–lock | อยู่ห้องเดียวกัน มองเห็นพร้อมกัน | อยู่คนละ sub-area ต้องจำ |
| ความตรงของ clue | สัญลักษณ์เหมือนกันเป๊ะ | ต้องแปล (ดอกไม้ → กินรี → ทิศตะวันออก) |
| จำนวนขั้น | 1–2 ขั้น | 4+ ขั้น (เก็บหลายชิ้น) |
| สัญญาณรบกวน | ไม่มีตัวหลอก | มีของคล้ายกันที่ไม่ใช่ |

เส้นโค้งทั้งเกม: บ้านยาย (ง่ายสุด, สอน) → ป่ากินรี (สอนกลไกดินแดน) → นาค/ครุฑ/อสูร (ยากขึ้น ลำดับเล่นอาจสลับได้ → แต่ละดินแดนต้องเล่นได้โดยไม่ต้องผ่านอีกดินแดนก่อน ถ้า Oak เลือกให้เลือกลำดับได้) → เขาเมรุ (บิด ใช้ทุกอย่าง)

ในด่านเดียว: puzzle เล็กอันแรกง่ายสุด, puzzle ใหญ่ยากสุด, หลัง puzzle ใหญ่ให้ "พัก" (cutscene, เดินทาง, บทพูด)

## 4. เวลาเป้าหมาย (ประมาณ ใช้ตอนเทสต์)

| ขนาด | เวลาเป้าหมายของคนเล่นครั้งแรก |
|---|---|
| puzzle เล็ก | 1–4 นาที |
| puzzle ใหญ่ | 5–12 นาที |
| ด่านทั้งด่าน | 15–30 นาที |
