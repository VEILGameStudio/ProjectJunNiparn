# 04 — มอนสเตอร์และกับดักแบบ puzzle

Oak ตัดสิน (2026-11-05): กับดักและมอนสเตอร์ **ยังมี** แต่ **ผ่านด้วยการแก้ puzzle ไม่ใช่การต่อสู้**
มอนหนึ่งตัว = puzzle หนึ่งอันของด่าน ตัวอย่างของ Oak: ใช้เทียนทำให้มันติด (ตัวอย่างเท่านั้น ยังไม่สั่งสร้าง)

## 1. สูตร: นิสัย → ช่องโหว่ → ของ/การกระทำ

ออกแบบมอนจาก **นิสัยเดียวที่ผู้เล่นสังเกตได้** แล้วให้นิสัยนั้นเป็นช่องโหว่

| ขั้น | คำถาม | ตัวอย่าง (เทียนของ Oak) |
|---|---|---|
| นิสัย | มันทำอะไรซ้ำๆ ที่ผู้เล่นเห็นได้? | ผีเสื้อกลางคืนยักษ์บินวนหาแสง |
| สอนนิสัย | ผู้เล่นเห็นนิสัยนี้ที่ไหนก่อนเจอมัน? | ฉากก่อนหน้ามีผีเสื้อตัวเล็กบินเข้าตะเกียง |
| ช่องโหว่ | นิสัยนี้ทำให้มันพลาดยังไง? | มันจะไปที่แสงที่สว่างที่สุดเสมอ |
| key | ผู้เล่นใช้อะไรกับช่องโหว่? | วางเทียนในกรงไม้ → มันบินเข้าไปติด |
| ผลทางเรื่อง | ผ่านแล้วโลกได้อะไร? | ปล่อยมันออกไปข้างนอกทีหลัง (ไม่ฆ่า — โทน cozy) |

## 2. รูปแบบที่เข้ากับระบบที่มี (ไม่ต้องใช้ AI)

ทุกแบบด้านล่างทำได้ด้วย `PuzzleBase`/`MiniGameBase` + UnityEvents + `HeldItemCheck` + Touch zone + animation
**ไม่ต้องมี monster AI หรือ pathfinding** (ซึ่งเป็น hard stop ใน CLAUDE.md §8 ต้องส่ง Oak)

| แบบ | มอน/กับดักทำอะไร | ผู้เล่นทำอะไร | ระบบ |
|---|---|---|---|
| **ผู้เฝ้าประตู** | ยืนขวางทาง ไม่ขยับ | ให้ของที่มันต้องการ / ทำให้มันหลับ / ทำให้มันกลัว | `Required Item` + Must Be Held, `OnPuzzleCompleted` → animation หลบ |
| **วนเป็นรอบ** (patrol แบบ animation) | เดินไป-กลับตาม animation เดิม | รอจังหวะ / ปิดทางเดินของมัน | Animator + Touch zone (ใช้ `HazardTrap` ได้ถ้าชนแล้วโดนผลัก — ต้องเป็น cozy ไม่ใช่ตาย) |
| **กับดักที่ปลดได้** | หนาม/เถาวัลย์/พื้นทรุด | หาวิธีปิด (คันโยก, puzzle เล็ก) | `HazardTrap` + `DisarmInteractable` (CLAUDE.md §6) |
| **มอนที่เป็น puzzle เอง** | มันตั้งปริศนา (ทายคำ, ลำดับ) | ตอบให้ถูก | Choice dialogue / `MiniGameBase` |
| **หลอกด้วยสภาพแวดล้อม** | ไวต่อเสียง/แสง/กลิ่น | ทำเสียง/แสงที่อื่นเบี่ยงความสนใจ | ปุ่ม/ของที่ wire `OnPuzzleCompleted` → มอนหันไปทางอื่น (animation) |

## 3. เช็กก่อนส่ง

- [ ] นิสัยของมันถูกสอน **ก่อน** เจอมัน (หรือในการเจอครั้งแรกแบบปลอดภัย)
- [ ] ไม่มีการตี/ยิง/ลดเลือดมอนในทางออกที่ถูก
- [ ] ถ้าผิดพลาด ผลคือ "ถอยกลับ/เริ่มใหม่" ไม่ใช่ตาย — ถ้าจำเป็นต้องใช้ game over ให้ระบุและถาม Oak
  (ระบบ game over มีแล้วใน CLAUDE.md §7 แต่ GDD เป็นเกม cozy)
- [ ] ไม่ต้องใช้ AI/pathfinding/การล็อก input เอง — ถ้าต้องใช้ เขียนลงการ์ดว่า "ติด hard stop §8" แล้วส่ง Oak
- [ ] มันมีที่มาในโลก: สัตว์หิมพานต์ที่สับสนเพราะมณีแตก ไม่ใช่ "ศัตรู" ลอยๆ — แก้แล้วมักได้ช่วยมันด้วย
- [ ] นับเป็นหนึ่งใน ~5 puzzle ของด่าน และอยู่ในผังพึ่งพา
