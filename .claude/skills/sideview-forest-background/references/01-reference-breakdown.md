# 01 — Reference breakdown (ถอดทีละชิ้น)

แหล่ง: คลิป gameplay 2 คลิป (1280×720, 19 วิ และ 74 วิ) + ภาพขั้นตอนทำงาน 3 ภาพ ของเกม side-view แนว hand-drawn
ฉากเดียวกันทั้งหมด: ป่าสนสูง + กระท่อมหลังคา A คลุมมอส + ต้น willow + ต้นไม้ใบกว้างทางซ้าย

> ใช้เพื่อ **ศึกษาเทคนิค** เท่านั้น ห้าม trace / copy รูปทรงหรือ asset ของเขาลงเกมเรา

---

## img/01-rough-layout-with-ui.jpg — Rough blocking (เส้นแดง)

- เริ่มจาก **UI ก่อน**: วงกลม DAY ตรงกลางบน, ช่อง slot ขวาบน, แถบสถานะ+inventory ด้านล่างเป็นแผ่นแดงทึบ
  → ศิลปินรู้ตั้งแต่แรกว่าพื้นที่เล่นจริงเหลือแค่ ~2/3 บนของจอ
- กรอบขาว = กรอบกล้อง, พื้นเทารอบนอก = ส่วนที่วาด **เกินกรอบ** (bleed) เผื่อ pan/zoom/จอกว้าง
- เส้นพื้นถูกล็อกเป็นเส้นตรงที่ขอบบนแถบ UI ตัวละครทุกตัวยืนบนเส้นเดียวกัน
- วางตัวละคร (ตัวเอก + ศัตรู 2 ตัว) ใน rough เลย เพื่อเช็กสเกลและพื้นที่ต่อสู้
- รูปทรงหลักครบแล้ว: ต้นใหญ่ซ้าย, ตอหัก, กระท่อม A กลาง, willow ขวา, กิ่ง/เถาวัลย์ห้อยจากขอบบนขวา (ปีกเวทีด้านบน)
- เส้นสเก็ตช์หลวม แต่ **silhouette ชัด** — ตัดสินใจเรื่องรูปทรงใหญ่ก่อน detail

## img/02-lineart-value-pass.jpg — Lineart + value

- พื้นหลังสีฟ้าเทา (= สีหมอก/บรรยากาศ) แล้วชั้นไกลทาเทาจางเกือบกลืนกับพื้น, ชั้นใกล้ทาเทาทึบกว่า
- เส้นดำมีน้ำหนักเท่ากันเกือบทุกชั้น แต่ value ของเนื้อต่างกัน → **ความลึกมาจาก value ไม่ใช่เส้น**
- มีเส้นกรอบ 2 ชั้น: กรอบใหญ่ (พื้นที่วาด) และกรอบในที่มี HUD → ใช้เช็กว่าจุดสำคัญไม่ไปอยู่ใต้ UI
- ต้นสนไกลวาดเป็นทรงสามเหลี่ยมซ้อนชั้นแบบเรียบ ๆ (iconic) — ไกลแค่ไหนรูปทรงยิ่งต้องเรียบ

## img/03-final-color-kit.jpg — Final color + asset kit

- วาดเป็น **ฉากเดียวยาวต่อเนื่อง** (ราว 14 เท่าความสูงตัวละคร) แล้วจะตัดเป็นชั้นภายหลัง
- แผ่นหลังสุดเป็นสี่เหลี่ยมสีเขียวเทาจาง (haze plate) — ไม่มี detail เลย ทำหน้าที่เป็น "อากาศ"
- ชั้นลำต้นถอยหลัง 3 ระดับ: ไกลสุดจางเกือบเป็นเงา, กลางเห็นลายเปลือก, ใกล้มีมอสเกาะ+กิ่งหัก
- ยอดลำต้นชั้นหน้าโผล่เหนือ haze plate และ **ถูกตัด/หัก** (snag) — silhouette บนขอบฟ้าไม่ซ้ำกัน
- Hero set: ต้นใบกว้างสีเขียวสด (ซ้าย), ตอไม้มอส, กระท่อม A ที่ "มอสกลืน", willow สีเขียวอมฟ้า (ขวา)
  → willow ตั้งใจใช้ hue ต่าง (teal) จากต้นซ้าย (lime) เพื่อแยกมวลซ้าย/ขวาไม่ให้กลืนกัน
- ขอบล่าง: แถบดินสีน้ำตาลอุ่น (สีร้อนสีเดียวในฉาก) → แยกพื้นออกจากป่าเขียวชัดเจน
- กล่องขวาล่าง = **prop kit** แยกชิ้น: หญ้า, เฟิร์น, เห็ด, ดอกไม้ขาว, ดอกเหลือง → เอาไปโรยหน้าฉาก/ใช้ซ้ำในฉากอื่น
- มอสสีเขียว lime ปรากฏ **ทุกชั้นใกล้** (ลำต้น ตอ กระท่อม พื้น) → motif เดียวที่ผูกทั้ง palette

## img/04-ingame-day.jpg / 05-ingame-dusk.jpg — คลิป 1 (ฉากต่อสู้)

- กล้อง **นิ่ง** เป็นจอเดียว (arena) ฉากทั้งฉากพอดีจอ แถบ UI ดำด้านล่าง ~22% ของจอ
- ตัวละครสูง ~14% ของความสูงจอ, กระท่อม ~2 เท่าตัวละคร, ลำต้นทะลุขอบบน
- **God rays** แนวตั้ง/เฉียงเล็กน้อยจากด้านบนกลาง ส่องผ่านช่องระหว่างลำต้น เป็นจุดสว่างที่สุดของฉาก
- เวลาเปลี่ยนระหว่างเล่น: ช่วงต้น = เขียวอมเหลือง แสงนวล → ช่วงหลัง = น้ำเงินเข้ม (ค่ำ/พระจันทร์)
  ฉากเดิมทุกพิกเซล เปลี่ยนแค่ grade + ความมืด → **ฉากถูกวาดให้ grade ได้**
- กลางคืนมี **คบเพลิง** ที่ศัตรูถือ เป็น local warm light + ไฟระเบิด/สกิลสีเหลืองส้ม → ตัดกับฉากฟ้าเย็นชัดมาก
- ตัวละครด้านมืดของฉากถูกทำให้มืดลงตาม (ไม่ได้สว่างลอยเท่ากันทั้งเกม)

## img/06-cutscene-wide.jpg / 07-cutscene-zoom.jpg — คลิป 2 (cutscene/dialogue)

- ฉากเดียวกันแต่ render ละเอียดกว่า: texture แบบสีน้ำ/กระดาษ, หมอกฟุ้ง, bloom ที่ไฟ, vignette มุมจอ
- **Letterbox** ดำบน–ล่าง ระหว่าง cutscene
- กล้อง **pan + zoom เข้าหาคนพูด** (~1.3–1.5 เท่า) แล้วถอยออกเมื่อจบบทพูด, เลือกตัวเลือก (Stop Father / Stop Plasmon) ขณะ zoom
- **Foreground lip**: เงาดำของหญ้า/ดินที่ขอบล่างจอ อยู่ **หน้า** ตัวละคร → ให้ความรู้สึกว่ากล้องอยู่ "ในป่า"
- กองไฟกลางฉากสร้าง pool of light สีส้ม เงาตัวละครรอบไฟ rim light อุ่น → จุดสนใจของ shot
- ชั้นไกลมี haze สีฟ้าเทา ทำให้ต้นสนหลังจางเกือบเป็นสีเดียวกับอากาศ

- คลิป 1 กล้องแทบไม่เลื่อน จึงวัด parallax ไม่ได้ชัด; คลิป 2 มี pan/zoom แต่ชั้นต่าง ๆ ดูเลื่อนด้วยอัตราใกล้กันมาก
