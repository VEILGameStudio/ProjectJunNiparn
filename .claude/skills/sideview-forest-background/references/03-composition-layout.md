# 03 — Composition, layout, มุมกล้อง

## 1. สัดส่วนจอ (วัดจาก reference 1280×720)

| สิ่ง | สัดส่วน |
|---|---|
| แถบ UI ล่าง (gameplay) | ~22% ของความสูงจอ |
| เส้นพื้น (ที่ตัวละครยืน) | ~73% จากบน (ขอบบนแถบ UI พอดี) |
| ความสูงตัวละคร | ~14% ของจอ (≈ 1/7) |
| กระท่อม (hero prop) | ~2× ตัวละคร |
| ลำต้นหลัก | สูงเกินจอ (ทะลุขอบบนเสมอ) |
| ความกว้างฉากเต็ม (final kit) | ~14× ความสูงตัวละคร |
| ช่องฟ้า/หมอกที่เห็น | ~ 1/3 บนของพื้นที่เล่น ถูกลำต้นตัดเป็นแถบแนวตั้ง |

ข้อคิด: ตัวละครเล็ก (1/7 จอ) + ต้นไม้ทะลุจอ = **scale contrast** ทำให้ป่ารู้สึกใหญ่และตัวละครเปราะบาง —
ถ้าเกมต้องการให้ตัวละครดูยิ่งใหญ่ ทำกลับกัน (ตัวใหญ่ขึ้น ต้นไม้โผล่ยอด)

## 2. โครงเวที (proscenium / stage wings)

```
 ┌──────────────────────────────────────────────┐
 │▓▓▓ canopy ▓▓  |   |  ║  |    |  ║   ~~vines~~│  ← ขอบบน: ใบ/กิ่งห้อย ปิดกรอบ
 │▓▓▓▓▓▓▓▓▓▓    |   ║  |  rays  |  ║  |        │
 │▓▓ LEFT WING  |   ║  /\   |    ║ ( WILLOW )  │
 │ ▓▓ (ต้นใหญ่)  ║   ║ /  \  |   ║ (  mass  )  │
 │  ▓  stump    ║   ║/ ▯▯ \ ║   ║ (  RIGHT )  │
 │══════════════════════☺═══════════════════════│  ← เส้นพื้น
 │               [  UI / HUD  ]                 │
 └──────────────────────────────────────────────┘
```

- **ปีกซ้าย** หนัก/มืด/ใหญ่ (ต้นใบกว้าง + ตอ) — ตาเริ่มอ่านจากซ้าย จึงต้องมีของ "จับตา" แล้วส่งเข้ากลาง
- **กลาง** = จุดสนใจ: รูปสามเหลี่ยม (หลังคา A) ชี้ลงหาประตู = ตำแหน่งตัวละคร; god rays ตกใกล้จุดนี้
- **ปีกขวา** = มวลโค้งนุ่ม (willow) ต่างรูปทรงจากซ้าย (ใบกว้างเป็นก้อน vs willow ห้อยเป็นม่าน) → สมดุลแบบไม่สมมาตร
- **ขอบบน** มีใบ/กิ่ง/เถาวัลย์ห้อย ปิดกรอบไม่ให้ตาหลุดขึ้นฟ้า
- **ขอบล่าง** = แถบพื้น + foreground lip

## 3. จังหวะลำต้น (vertical rhythm)

- ระยะห่างแบบ **ยาว–สั้น–กลาง–สั้น–ยาว** ไม่ใช่เท่ากัน (ระยะเท่ากัน = รั้ว ไม่ใช่ป่า)
- ความกว้างลำต้นต่างกันอย่างน้อย 3 ขนาดในชั้นเดียว
- ลำต้นเอียงได้นิดหน่อย (1–4°) บางต้น — ตรงหมดดูแข็ง เอียงมากดูเมา
- ห้ามลำต้นต่างชั้นซ้อนเป็นเส้นเดียวกันพอดี (เหมือนต้นเดียวหนาขึ้น) — เลื่อนให้เหลื่อม
- ยอดที่โผล่: หัก, ตอ, มีกิ่งแห้ง — silhouette บนท้องฟ้าคือที่ที่ตาอ่านรูปทรงชัดที่สุด ใช้ให้คุ้ม

## 4. รูปทรงและการนำสายตา

- **Big–Medium–Small**: มวลใหญ่ 1–2 ก้อน (ต้นซ้าย, willow), กลาง 2–3 (กระท่อม, ตอ, ขอนไม้), เล็กเยอะ (เห็ด, ดอก, หญ้า)
- **รูปทรงหลักต่างกัน**: ก้อนกลม (ต้นใบกว้าง) / สามเหลี่ยม (กระท่อม, สน) / ม่านห้อย (willow) / แท่งตั้ง (ลำต้น)
- **เส้นนำสายตา**: หลังคา A, กิ่งต้นซ้ายที่ยื่นเข้ากลาง, god rays เฉียง → ทั้งหมดชี้ไปที่ประตูกลาง
- **Negative space**: ช่องหมอกระหว่างลำต้นต้องมีขนาดต่างกัน — ช่องที่ใหญ่สุดควรอยู่ใกล้จุดสนใจ (rays ลอดได้)

## 5. มุมกล้อง

- Reference เป็น **side-view ตรง (eye-level)** เส้นขอบฟ้าอยู่ราวระดับหัวไหล่–หัวตัวละคร
  → เห็นพื้นเป็นแถบบาง ๆ ไม่เห็นพื้นจากบน; ทุกอย่างอ่านเป็น silhouette ด้านข้าง
- ต้นไม้วาดแบบ **ไม่มี perspective แนวตั้ง** (ลำต้นขนาน ไม่ลู่) — เหมาะกับกล้องที่ pitch ต่ำมาก
- ถ้ากล้องเงยนิด ๆ ยิ่งรู้สึกต้นไม้สูง; ก้มนิด ๆ เห็นพื้นมากขึ้น เหมาะเกม puzzle ที่ต้องเห็นของบนพื้น
- ฉากที่ต้องเดินผ่าน: ให้มี "จุดหยุดตา" ทุก ~1 ความกว้างจอ (กระท่อม, ตอใหญ่, แสงส่อง) ไม่งั้นป่ายาวจะน่าเบื่อ

## 6. ความอ่านง่ายสำหรับ gameplay

- พื้นที่ระดับตัวละคร (เส้นพื้น ถึง ~1.5 เท่าความสูงตัวละคร) ต้อง **value ต่างจากตัวละคร** — ในอ้างอิงคือพุ่มเขียวกลาง ๆ
  ตัวละครเส้นหนาสีอิ่ม จึงไม่จม
- ของที่ "คลิกได้/เป็นของจริงในเกม" ควรมีเส้นหนาเท่าตัวละคร ของที่เป็นแค่ฉากเส้นบางกว่า (อ่านแยกได้ทันที)
- อย่าวาง detail ถี่ที่สุดไว้ด้านหลังตัวละครพอดี — detail ถี่เก็บไว้ที่ปีกซ้าย/ขวา
