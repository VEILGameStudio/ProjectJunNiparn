# 04 — Production pipeline (rough → final → asset)

ขั้นตอนตามที่เห็นในภาพ 01 → 02 → 03 บวกขั้นที่ senior จะทำเพิ่ม

## ขั้น 0 — Brief (5 นาที)

ตอบให้ได้ก่อนจับปากกา:
- ฉากนี้เป็นอะไรใน gameplay? (arena นิ่ง / ทางเดิน scroll / ห้อง puzzle / cutscene)
- อารมณ์หลัก 1 คำ (ลึกลับ, อบอุ่น, อันตราย, เศร้า) และเวลา (กลางวัน/เย็น/คืน)
- จุดสนใจ 1 จุด คืออะไร ตัวละครยืนตรงไหน
- กล้องเลื่อนไหม zoom ไหม → กำหนดว่าต้องวาดเกินกรอบเท่าไร

## ขั้น 1 — Rough blocking (ภาพ 01)

1. สร้าง canvas ขนาดจอ (เช่น 1920×1080) + **bleed** รอบนอก (ซ้าย/ขวา ≥ ระยะ pan + ส่วนเผื่อ 21:9, บน/ล่าง ≥ 10–15% เผื่อ zoom)
2. วาง **UI mockup** ทับก่อน (HUD, dialogue box, inventory) → ระบายพื้นที่ที่ UI บังเป็นสีทึบ
3. ลากเส้นพื้น, วางตัวละคร 1–3 ตัวขนาดจริง
4. Block มวลใหญ่: ปีกซ้าย, ปีกขวา, จุดสนใจกลาง, ขอบบน
5. สเก็ตช์ลำต้นเป็นแท่งเส้นเดียว จัดจังหวะ (ดู 03 §3)
6. **Thumbnail test**: ย่อเหลือ 200 px กว้าง — ยังอ่านปีกซ้าย/กลาง/ขวาออกไหม? ถ้าไม่ กลับไปแก้ก่อน

## ขั้น 2 — Lineart + value (ภาพ 02)

1. ถม canvas ด้วยสีอากาศ (ใน ref คือฟ้าเทา)
2. แยก layer ตามตาราง 02 ตั้งแต่ตอนนี้ (L0…L6) — **อย่าวาดรวมแล้วค่อยแยก** จะเสียเวลาซ่อมขอบที่ถูกบัง
3. ลงเส้น: ใกล้หนา/ไกลบาง หรือเส้นเท่ากันแต่ไกลเปลี่ยนสีเส้นให้จางลง
4. ระบายเทาทึบต่อชั้นตามช่วง value ในตาราง
5. **Squint test**: หรี่ตาดู → ต้องเห็นเป็น 3–4 ก้อน value ชัด ๆ ถ้าเห็นเป็นโจ๊ก = ชั้นต่างกันไม่พอ
6. เช็กกรอบ UI อีกครั้ง

## ขั้น 3 — Color & render (ภาพ 03)

1. ลงสีพื้นแต่ละชั้นด้วย layer mode Color/Overlay บน value เดิม (หรือใช้ gradient map) — value ต้องไม่เพี้ยนจากขั้น 2
2. Render ชั้นใกล้ก่อน (ใช้เวลามากสุดที่ hero set) ชั้นไกลทำน้อยลงเรื่อย ๆ
3. ใส่ motif เชื่อมทั้งฉาก (ใน ref คือมอส lime) — ปรากฏทุกชั้นใกล้ แต่ไม่ถึงชั้นไกล
4. ใส่ aerial perspective: layer สีอากาศทับแต่ละชั้นด้วย opacity ตามระยะ (02)
5. **วาดเป็นกลางเรื่องแสง** ถ้าเกมมี time-of-day — อย่า bake แสงเย็นสีส้มลงไปในสีฐาน (จะ grade ไปกลางคืนไม่ได้)
   ให้ bake แค่ form shading (เงาด้านข้าง), ทิศแสงหลักจากบน-หลัง

## ขั้น 4 — แยก asset + kit

- Export ทีละชั้นเป็น PNG โปร่งใส ขอบตัดสะอาด (เกม alpha clip → ห้ามขอบฟุ้งกึ่งโปร่ง ยกเว้น L0/hazes ที่ทึบอยู่แล้ว)
- **วาดส่วนที่ถูกบังเผื่อ** ประมาณ 10–20% — เมื่อ parallax เลื่อน ชั้นหลังจะโผล่ส่วนที่ถูกชั้นหน้าบังเดิม
- แยก **prop kit** (หญ้า เห็ด ดอก เฟิร์น ก้อนหิน กิ่งไม้) เป็นชิ้น ๆ ไว้โรยซ้ำ ปิดรอยต่อ และใช้ในฉากถัดไป
- ต้นไม้ซ้ำได้: ทำลำต้น 3–5 แบบต่อชั้น + ยอดหัก 3 แบบ + มอส decal → ประกอบกันได้หลายสิบต้นโดยไม่ซ้ำตา
- Layer ที่กว้างมาก (L0/L1) แบ่งเป็น tile ต่อกันได้ ขอบซ้าย-ขวาต่อเนียน

## ขั้น 5 — Lighting & FX pass (ทำในเกม ไม่ใช่ในไฟล์ภาพ)

- God rays, หมอก, ฝุ่นลอย/หิ่งห้อย, bloom, vignette, color grade ต่อเวลา, local light (ไฟ, คบเพลิง)
- ดู 05 และ 06

## เวลาโดยประมาณ (ฉากขนาด ref, ศิลปินคนเดียว)

| ขั้น | เวลา |
|---|---|
| Brief + rough | 0.5–1 วัน |
| Lineart + value | 1–2 วัน |
| Color + render | 2–4 วัน |
| แยก asset + kit | 1 วัน |
| ลงเกม + light/FX + ปรับ | 1–2 วัน |
