# 09 — Value & color study: reference vs ฉากป่าของเรา

ภาพทั้งหมดอยู่ที่ `references/img/study/` (ทำด้วย L* ของ CIELAB ซึ่งใกล้กับความสว่างที่ตาเห็น ไม่ใช่ค่าเฉลี่ย RGB)
แบ่ง value 4 ช่วง: มืด < 20 / กลางมืด 20–40 / กลางสว่าง 40–60 / สว่าง > 60

อ่านตารางยังไง:
- **ref ในเกมมืดเป็นส่วนใหญ่ (85% อยู่ใต้ 40)** แต่มี "สว่างจริง" 4% — นั่นคือช่องหมอกและ god rays ที่ตาพุ่งไปหา
  ภาพจะดูมีแสงได้ไม่ใช่เพราะสว่างทั้งภาพ แต่เพราะมีจุดสว่างเล็ก ๆ ตัดกับความมืด
- **ของเรา 0% ในช่วงสว่าง** → ไม่มีอะไรนำสายตา ไม่มีแสง ไม่มีอากาศ = ภาพ "ทึบ" แม้สีจะสดกว่า ref
- ภาพ kit (ไม่มีเงาในเกม) สว่างกว่าในเกมมาก → ref วาด asset ค่อนข้างสว่างแล้ว **มืดลงด้วยแสง/grade ในเกม**
  เราควรทำแบบเดียวกัน: อย่าวาด asset มืด เพราะจะทำค่ำ/กลางวันจาก asset เดียวไม่ได้

## 2. Palette (k-means 10 สี เรียงมืด → สว่าง) — `p01-palettes-ref-vs-ours.jpg`

| ภาพ | สีหลัก (สัดส่วนบนจอ) |
|---|---|
| ref กลางวัน | `#191F1B` 21%, `#292F24` 26%, `#384431` 21%, `#4C5C4E`, `#55622B` (มอส), `#6B7F74`, `#95A291`, `#C2CFB2`, `#EAF6DE` (แสง) |
| ref ค่ำ | `#0D1518` 31%, `#162221` 22%, `#26322B`, `#263D54` (หมอกฟ้า), `#414D35`, `#5E6C66`, `#CA9842` (คบเพลิง), `#CDE0D0` (แสงจันทร์) |
| ref cutscene | `#273128`, `#3C4A3D`, `#516754`, `#66836A`, `#7CA479`, `#BCB099` (หมอกอุ่น 12%), `#D48B4A` (ไฟ) |
| **ของเรา** preview | `#332C23` **48% (ดินน้ำตาล)**, `#20281C`, `#2D3823`, `#3D4426`, `#4A5229`, `#58602A`, `#696E30`, `#7E8033`, `#989636` |

ข้อสังเกต:
1. **ของเราไม่มีสี "อากาศ"** — ref ทุกภาพมีกลุ่มสีเขียวเทา/ฟ้าเทาสว่าง (`#95A291`, `#C2CFB2`, `#BCB099`) ที่เป็นหมอก ของเราไม่มีเลย
2. **ของเราเหลืองทั้งภาพ** — ทุกเขียวของเราอยู่ฝั่งเหลือง-มะกอก (hue ~65–75°) ref แยกเป็น 2 กลุ่ม: เขียวเทาเย็น (ฉาก, ~110–140°) + เหลืองมะกอก (มอส accent เท่านั้น)
   → ถ้าทุกอย่างเหลืองเท่ากัน ก็ไม่มีอะไรเป็น accent
3. **ดินกินพื้นที่ 48%** ใน preview และราว 40% ของจอในกล้อง SideView จริง (กล้องก้ม 10° สูง 5.5 unit เห็นพื้นเยอะ)
   ref ปิดพื้นด้วยแถบ UI แต่เกมเราไม่มีแถบนั้น → **พื้นต้องถูกออกแบบ** (ดูข้อ 4)
4. สีไฟ/accent ร้อน: ref มีเสมอ (คบเพลิง กองไฟ) ของเรายังไม่มีแหล่งแสงอุ่นเลย

## 4. สิ่งที่ grade อย่างเดียวแก้ไม่ได้ (ต้องมีอาร์ตหรือจัดใหม่)

ดูภาพจำลอง `s01-test-forest-before-after.jpg` — หลังปรับสี ชั้นไกลจางเข้าหมอกถูกทิศแล้ว แต่ยังขาด:

1. **ลำต้นสูงตรง** — ต้นไม้ที่มีตอนนี้ (Willow, OakBig, Bushy, OakRound, Banana) เป็นทรงพุ่มกลมทั้งหมด
   พุ่มชนกันจนปิดฟ้า หมอกโผล่ได้แค่แถบเดียว → ต้องการ asset **ลำต้นสน/ลำต้นสูงไม่มีพุ่ม 3–5 แบบ** สำหรับแถว Mid/Far/Deep
2. **ช่องว่าง** — แถว Mid มีต้นทุก ~4 unit ทรงพุ่มกว้าง ~6 unit จึงซ้อนกันหมด ต้องเว้น 1–2 ช่องใหญ่ให้หมอกส่องลงมา (ใกล้จุดสนใจ)
3. **พื้น** — แถบดินเรียบกว้าง 40% ของจอ ต้องมี: ไล่ความมืดลงขอบล่าง, หญ้า/ใบไม้ร่วงเป็นหย่อม, รากไม้, ทางเดินสีอ่อนกว่ารอบ ๆ, และ foreground lip มืดที่ขอบล่างจอ
4. **จุดสนใจ** — ref มีกระท่อม A ตรงกลาง ฉากเรายังไม่มี hero prop
5. **แสง** — god rays, ฝุ่น, ไฟ ต้องอนุมัติตามกฎ alpha clip (ดู 06)
