# 05 — สี แสง หมอก บรรยากาศ

## 1. Palette ของ reference (ประมาณจากการดูดสีภาพ final kit)

| บทบาท | สีประมาณ | Hue | ลักษณะ |
|---|---|---|---|
| อากาศ / haze (L0) | `#A9C8A6` | เขียวเทา ~115° | สว่าง, sat ต่ำ |
| สนไกล (L1–L2) | `#586956` | เขียวเทา ~115° | กลาง, sat ต่ำ |
| ลำต้นกลาง (L3) | `#858A65` ด้านสว่าง / `#3A3A32` ด้านเงา | เหลืองมะกอก ~55–70° | sat ต่ำ |

| Willow (L4) | `#5C805E` → เงา `#405647` | เขียวอมฟ้า ~125–140° | ต่างจากต้นซ้ายโดยตั้งใจ |
| มอส accent | `#A3B433` | lime ~68° | **สดที่สุดในฉาก** |

| ดิน | `#4E3527` | น้ำตาลส้ม ~20° | **อุ่นสีเดียว** |
| ไฟ/คบเพลิง | ส้มเหลือง ~35–45° | | จุดร้อน + bloom |

สังเกต:
- **เงาไม่เคยเป็นดำสนิท** — เป็นเขียวเข้มมาก ๆ ยกเว้น foreground lip
- Hue ของชั้นไกลเลื่อน **เข้าหาสีอากาศ** (เขียวเทา/ฟ้า) ส่วนชั้นใกล้เลื่อนไปทาง **เหลือง** (อุ่นกว่า) — warm-near / cool-far
- Saturation สูงอยู่แค่ 2 ที่: มอส (ชั้นใกล้) และไฟ — ที่เหลือ sat ต่ำ ทำให้ 2 อย่างนี้เด่น

## 2. Value structure

- 3 ก้อนใหญ่: **สว่าง** (อากาศ + rays) / **กลาง** (ลำต้นไกล-กลาง, willow) / **มืด** (ชั้นใกล้, เงาใต้พุ่ม, พื้น)
- จุดสว่างที่สุด = ช่องหมอกที่ rays ลอด, ใกล้จุดสนใจกลาง
- จุดมืดที่สุด = ประตูกระท่อม / ใต้พุ่ม → อยู่ติดจุดสว่าง (มอสบนหลังคา) = contrast สูงสุดตรงจุดสนใจ

## 3. แสง

- **Key light**: จากบน-หลัง ผ่านเรือนยอด (ไม่เห็นดวงอาทิตย์) → ขอบบนของใบ/มอสสว่าง, ด้านหน้าลำต้นมืด
- **God rays**: แท่งแสงเฉียง 5–15° จากแนวตั้ง, กว้างไม่เท่ากัน, ขอบนุ่ม, อยู่ **ระหว่าง L2 และ L3**
  (หน้าชั้นไกล หลังชั้นกลาง) จึงดูเหมือนอยู่ในอากาศ ไม่ใช่แปะหน้าจอ; ขยับ opacity ช้า ๆ 3–8 วินาที/รอบ
- **Bounce**: แสงเขียวสะท้อนจากพื้นมอสขึ้นใต้ใบ — ใส่สีเขียวอิ่มนิด ๆ ในเงาด้านล่างของใบ
- **Rim light** บนตัวละครในฉากย้อนแสง: เส้นสว่างบาง ๆ ด้านหลัง ช่วยแยกตัวออกจาก BG มืด
- **Local light** (กองไฟ, คบเพลิง): วงแสงส้มบนพื้นและตัวละครรอบ ๆ + bloom + flicker ความเข้ม ±10–20% ไม่สม่ำเสมอ

## 4. หมอก / atmosphere

- หมอกหนาที่ล่างและไกล บางที่บนและใกล้ — ใน ref ช่วงล่างของชั้นไกลจางกว่าช่วงบน (ground fog)
- แผ่นหมอกเลื่อนช้า (1–3 px/วินาที ที่ 1080p) ระหว่างชั้น ทำให้ฉากนิ่ง "หายใจ"
- ฝุ่น/ละอองลอยในแท่งแสง (particles จุดเล็ก ช้า สว่างเฉพาะใน rays) — งบน้อยแต่ได้ความลึกมาก
- Vignette มุมจอมืดลง 15–25% (คลิป cutscene) ดึงตาเข้ากลาง

## 5. Time of day (ฉากเดียว หลายเวลา)

ทำแบบ reference: ภาพฐานกลาง ๆ แล้วเปลี่ยนด้วย grade

| เวลา | Grade | Haze/fog | Rays | Local light |
|---|---|---|---|---|
| กลางวัน | อุ่นเล็กน้อย, เขียวเหลือง, exposure ปกติ | เขียวเทาสว่าง | ชัด สีเหลืองอ่อน | ไม่เด่น |
| บ่าย/เย็น | อุ่นขึ้น ส้มทองที่ highlight, เงาม่วง | ส้มอมเทา | เฉียงมากขึ้น ยาว | เริ่มเห็นไฟ |
| ค่ำ (คลิป 1 ช่วงหลัง) | **เงาน้ำเงิน**, sat ลด, exposure −0.7 ถึง −1.2 | ฟ้าน้ำเงินเทา | ขาวอมฟ้า (แสงจันทร์) บางลง | **คบเพลิง/ไฟเด่นมาก** |
| กลางคืน | น้ำเงินเข้ม, contrast สูง | เข้ม เกือบดำที่ไกล | แทบไม่มี | ไฟเป็นแหล่งแสงหลัก + หิ่งห้อย |

กฎ: **มอส accent และไฟต้องยังอ่านออกทุกเวลา** — ถ้ากลางคืนมอสหายไป ฉากเสีย identity

## 6. Texture / ความเป็นงานมือ (คลิป 2)

- grain กระดาษ/สีน้ำ overlay บาง ๆ ทั้งจอ (opacity 5–10%) — ทำให้ภาพ digital ดูเป็นภาพวาด
- ขอบสีแบบ watercolor bleed ในชั้นไกล, ขอบคมในชั้นใกล้ → ความคม = ความใกล้ (เลียนแบบ depth of field)
