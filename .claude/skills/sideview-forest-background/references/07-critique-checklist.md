# 07 — Critique checklist + ข้อผิดพลาดที่เจอบ่อย

ไล่ทุกข้อด้วย screenshot ในเกม (ไม่ใช่ไฟล์ภาพ) ที่ 16:9 และ 21:9

## A. อ่านออกไหม (readability)
- [ ] ย่อ screenshot เหลือ 200 px กว้าง: ยังเห็นปีกซ้าย / จุดสนใจกลาง / ปีกขวา
- [ ] แปลงเป็นขาวดำ: ยังแยกชั้นไกล–กลาง–ใกล้ได้ (3 ก้อน value)
- [ ] ตัวละครทุกตัวอ่านออกทั่วทั้งเส้นทางเดิน (ไม่จมกับพุ่มหรือเงา)
- [ ] ของที่ interact ได้ ต่างจากของฉาก (เส้น/สี/แสง)
- [ ] ไม่มีจุดสำคัญอยู่ใต้ UI หรือ dialogue box

## B. ความลึก
- [ ] แต่ละชั้นต่างจากชั้นข้าง ๆ ≥ 2 แกน (value / sat / เส้น / detail)
- [ ] ชั้นไกลเข้าใกล้สีอากาศ ชั้นใกล้ contrast สูง
- [ ] ทุกชั้นซ้อนทับกัน ไม่มี tangent (ขอบแตะกันพอดี)
- [ ] โคนต้นไม้ทุกต้นมีของปิด
- [ ] parallax เลื่อนเป็นขั้น ไม่มีสองชั้นที่ความเร็วเกือบเท่ากัน

## C. Composition
- [ ] ลำต้นระยะห่าง/ความกว้างไม่เท่ากัน, ทะลุขอบบน
- [ ] silhouette ยอดไม้ไม่ซ้ำ
- [ ] มีเส้นนำสายตาเข้าจุดสนใจ
- [ ] ช่องว่างใหญ่สุด/สว่างสุดอยู่ใกล้จุดสนใจ
- [ ] ฉากยาว: มีจุดหยุดตาทุก ~1 จอ

## D. สี/แสง
- [ ] accent สด ≤ 2 อย่าง (เช่น มอส + ไฟ)
- [ ] เงาไม่ใช่ดำสนิท (ยกเว้น foreground lip)
- [ ] warm-near / cool-far
- [ ] ทุก time-of-day ยังเห็น accent
- [ ] local light มีผลบนพื้นและตัวละครรอบ ๆ

## E. เทคนิค
- [ ] PPU ตามระยะ (ไม่ใช่ PPU ตัวละครทุกชั้น)
- [ ] เดินสุดขอบ + 21:9 ไม่เห็นขอบภาพ
- [ ] ขอบ alpha สะอาด ไม่มีขอบขาว/ฟุ้ง
- [ ] ชั้นหลังวาดเผื่อส่วนที่ถูกบัง

## ข้อผิดพลาดที่เจอบ่อย → วิธีแก้

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| ฉาก "แบน" ทั้งที่มีหลายชั้น | ชั้นต่างกันแค่สี value ใกล้กัน | ดัน value ชั้นไกลให้สว่างเข้าหาสีอากาศ, ลดเส้น/detail |
| ป่าดูเหมือนรั้ว | ลำต้นระยะเท่ากัน ขนาดเท่ากัน | สลับ ยาว-สั้น-กลาง, 3 ขนาด, เอียงบางต้น |
| ตัวละครจม | value BG ที่ระดับตัวละครเท่ากับตัวละคร | ทำแถบหลังตัวละครให้มืดหรือสว่างกว่า, เพิ่ม rim light |
| ฉากรก | detail ถี่ทุกที่ | detail เต็มเฉพาะ hero set, ที่เหลือลดลงตามระยะ |
| กลางคืนแล้วฉากตาย | bake แสงอุ่นในภาพฐาน / ไม่มี local light | วาดฐานกลาง ๆ, ใส่ไฟ/คบเพลิง, รักษา accent |
| ชั้นไกลเล็กผิด | export ด้วย PPU ตัวละคร | PPU = 1080 ÷ (0.335 × D) |
| เห็นขอบภาพตอน pan | ไม่ได้บวกระยะเลื่อนกล้อง T | กว้าง = 0.335 × D × 2.333 + T |
| foreground บังเกม | lip สูงเกิน / สว่างเกิน | สูง ≤ 8% จอ, มืดเกือบดำ, ไม่มี detail |
