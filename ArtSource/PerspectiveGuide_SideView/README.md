# Perspective guide — SideView (one-point perspective + grid box)

ไกด์ perspective สำหรับวาดฉาก 2.5D (`SideView`) ทับ คำนวณจากกล้อง `SideView` ของเกมจริง
(`CameraPreset.cs`: perspective, FOV 11.2, pitch 10, yaw 0, distance 20, target offset Y 1.63) ที่ 1080p
กล่องทุกใบเป็น grid box แบบเดียวกับ `BlockoutKit_ThreeQuarter`: เส้นเข้มทุก 1 unit เส้นจางทุก 0.25 unit ตรงกับกริดโลกจริง

## ตัวเลขสำคัญ (1920x1080)

| | ค่า |
|---|---|
| จุดรวมสายตา (VP) | **x 960, y −431** = กลางจอ แต่อยู่ **เหนือขอบบนจอ 431 px** (ที่ 2x: 1920, −862) |
| เส้นขอบฟ้า (horizon) | y −431 เส้นแนวนอนผ่าน VP = ระดับตากล้อง สูงจากพื้น 5.10 unit |
| เท้าผู้เล่น | x 960, y 976 (ตัวสูงประมาณ 430 px) |
| พื้นที่ขอบล่างจอ / ขอบบนจอ | z −1.4 / z 46.6 (ผู้เล่นอยู่ z 0) |
| เส้นตั้ง | เอียงเข้าหาจุดที่ 3 ไกลมากใต้จอ เอียงสุดแค่ 1.7° ที่ขอบจอ วาดตั้งตรงได้เลย |

ทำไม VP อยู่นอกจอ: กล้องก้มลง 10° ขอบฟ้าจึงขึ้นไปอยู่เหนือภาพ และ FOV 11.2 แคบมาก
เส้นลึกในจอจึงลู่เข้าหากันน้อย ภาพดูเกือบแบน นี่คือลักษณะของกล้องเกมจริง ไม่ใช่ไกด์ผิด

กติกา one-point ของกล้องนี้:
1. เส้นที่วิ่งเข้าลึก (แกน z ของโลก) ทุกเส้นลากไปที่ VP
2. เส้นขวางจอ (แกน x) เป็นแนวนอนเสมอ ไม่ลู่
3. เส้นตั้ง (แกน y) ตั้งตรง (ค่าจริงเอียงไม่ถึง 2° ดู layer สีม่วง)

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `scene_layered_2x.psd` | ฉากตัวอย่าง (ทางเดิน + ขั้นบันได + ลาน + บ้าน + กล่อง) แยก layer ทีละชิ้น + layer ไกด์ + layer "paint here" ผืนผ้าใบขยายให้เห็น VP |
| `scene_frame_2x.png` / `_1x` | ฉากตัวอย่าง ขนาดจอเกมพอดี (3840x2160 / 1920x1080) มีเส้นไกด์ |
| `scene_frame_2x_clean.png` | ฉากเดียวกัน ไม่มีเส้นไกด์ มีแต่ grid box |
| `scene_extended_1x.png` | จอ 16:9 + กรอบ 21:9 + ขอบเผื่อด้านบนให้เห็น VP กับเส้น ray |
| `cube_field_*.png` | กล่อง 1x1x1 วางทั่วจอหลายระยะ (แบบชีทฝึก perspective ในรูปอ้างอิง) ดูว่ากล่องหน้าตาเป็นยังไงในแต่ละตำแหน่งของจอ |
| `guide_numbers.json` | ตัวเลขทั้งหมดที่ใช้วาด |

Layer ไกด์ใน PSD (ปิด/เปิดได้): เส้น ray จาก VP, horizon + VP, แถวความลึก D 20/30/40/60/100
(บอกความเร็ว parallax และ PPU ของแต่ละระยะ ตาม CLAUDE.md §1), เส้นตั้งจริง (ม่วง), กรอบความสูงผู้เล่น, กรอบจอ 16:9 / 21:9

## ข้อควรรู้

- ภาพนี้ใช้กับพื้นที่ `SideView` เท่านั้น ห้ามใช้กับ `ThreeQuarter` (ใช้ `BlockoutKit_ThreeQuarter`)
- ใน perspective กล่องใบเดียวกันหน้าตาต่างกันตามตำแหน่งบนจอ จึงไม่มีชิ้นแยกให้เอาไปวางซ้ำเหมือน kit 3/4
  ให้ใช้ฉากตัวอย่าง หรือ `cube_field` เป็นแบบ แล้ววาดตามเส้น ray
- ของที่เป็นก้อนทึบในเกมเป็นโมเดล 3D (CLAUDE.md §7) ภาพนี้ใช้เป็น concept / paintover / แบบปั้นโมเดล
- ฉากหลังที่จะเป็น layer parallax: ระยะ D ยิ่งไกลยิ่งเลื่อนช้า (20/D) และใช้ PPU ตามแถว D ในภาพ
- sprite ยืน (ตัวละคร ต้นไม้ ป้าย) ที่จะเข้าเกม ต้องยืด **x 1.015** ตอน export แล้วเก็บใน `Art/Sprites/SideView/`
- ถ้าค่ากล้อง `SideView` เปลี่ยน ให้แก้ `CAMERA` ใน script แล้วรันใหม่ ไกด์จะตรงกับกล้องใหม่

## สร้างใหม่

```
pip install pillow numpy psd-tools
python3 tools/build_perspective_guide.py
```

แก้ฉากตัวอย่างที่ `scene_pieces()` และชีทกล่องที่ `cube_field_pieces()` ใน script (ใช้เวลารันประมาณ 6 นาที)
